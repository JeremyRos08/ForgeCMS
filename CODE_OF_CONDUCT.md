# Code de conduite ForgeCMS

ForgeCMS accueille les contributions de toute personne souhaitant améliorer le projet.

## Comportement attendu

Les échanges doivent rester professionnels, techniques et respectueux. Les contributeurs sont invités à :

- critiquer les idées et le code, pas les personnes ;
- expliquer les désaccords avec des arguments vérifiables ;
- accepter la revue de code et les demandes de modification ;
- éviter le harcèlement, les insultes, les attaques personnelles et la discrimination ;
- ne pas publier d'informations privées ou sensibles appartenant à d'autres personnes.

## Modération

Les mainteneurs peuvent modifier, masquer ou supprimer des contributions et échanges qui nuisent au projet ou enfreignent ces règles. Selon la gravité ou la répétition, un participant peut être temporairement ou définitivement exclu des espaces du projet.

## Portée

Ces règles s'appliquent aux issues, Pull Requests, discussions, commentaires, revues de code et autres espaces officiels liés à ForgeCMS.

## Signalement

Pour un problème de sécurité, utilisez la procédure décrite dans `SECURITY.md`. Pour un problème de comportement, contactez directement le mainteneur du dépôt plutôt que d'ouvrir une discussion publique contenant des informations sensibles.
